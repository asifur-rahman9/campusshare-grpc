CampusShare

Distributed equipment reservation · gRPC · 3 nodes

CampusShare manages shared equipment across three campuses. Each campus runs an independent server that is the sole authority for its own inventory. The servers coordinate over gRPC to search availability, place reservations and allocate released units to waiting users, with no shared database and no single point of failure.
